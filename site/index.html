did-theme-template

DIDAY-Theme für pptxgenjs: Farben, Schrift und Masterfolien nach der Präsentationsvorlage des Digital Independence Day. Damit lassen sich DI-Day-Vorträge als Code schreiben und als PowerPoint und PDF bauen.

Beispiel herunterladen (PPTX) Quellcode auf GitHub

Die Palette landet als Theme der PPTX. pres.SchemeColor.accent1 usw. zeigen also auf die DIDAY-Farben. Schrift für Überschriften und Text ist Noto Sans.

Masterfolien

MasterAussehenPlatzhalter
TITELoben Gelb mit großem Logo, unten Lilatitle, body, quelle
AUSSAGEKernaussage in grün umrandeter Sprechblase auf Gelbtitle, body, quelle
INHALTweiß, gelbes Kopfband mit Titel und Einleitungtitle, lead, quelle
INHALT_DUNKELwie INHALT, aber auf Lilatitle, lead, quelle

Alle vier im Format 16:9, mit der Fußzeile der Vorlage: Datum links, Text in der Mitte, Seitenzahl rechts.

Benutzen

pnpm add pptxgenjs sharp github:bmmmm/did-theme-template
const pptxgen = require("pptxgenjs");
const did = require("did-theme-template");

(async () => {
  const pres = new pptxgen();
  await did.setup(pres, { date: "01.11.2026", footer: "Datenburg & Brotfabrik", logo: "diday-logo.svg" });

  const s = pres.addSlide({ masterName: did.MASTER.INHALT });
  s.addText("Was macht ein Passwortmanager?", { placeholder: "title" });
  s.addText("Stell ihn dir vor wie einen Tresor.", { placeholder: "lead" });

  await pres.writeFile({ fileName: "vortrag.pptx" });
  await did.finish("vortrag.pptx"); // Farbpalette und Sprechblase
})();

did.setup kommt vor das erste addSlide, did.finish nach writeFile. Mehr steht in der README.

Logo

Das DIDAY-Logo ist nicht enthalten. Es gehört dem Digital Independence Day und steht nicht unter einer offenen Lizenz. Wer die offizielle Vorlage hat, übergibt das Logo daraus als logo an setup. Ohne Logo bleiben die Plätze frei.

English

Unofficial pptxgenjs theme that reproduces the slide template of Germany's Digital Independence Day: palette, Noto Sans and four slide masters with the template's footer. The DIDAY logo is not included; pass your own copy via logo.

Inoffiziell: Dies ist kein Projekt des Digital Independence Day. Name und Logo „DIDAY“ gehören dem Digital Independence Day. Code unter Apache-2.0.
